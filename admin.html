Create Sirski Member Login

Select an existing driver. The system prepares a personalized @sirski-transport.com login address. The driver's existing Spinner points remain unchanged.

Personalized Sirski login: the address is generated from the driver's TrucksBook username, for example hiyaw@sirski-transport.com. This is a login identity only; no Google Workspace mailbox is required. The password is handled by Supabase Auth.

🔗 Link Existing Member Login

Use this when a member already has a Sirski/Supabase login but their driver record shows Not linked. This does not create or delete an account.

No Supabase User ID is required. Select the member's existing @sirski-transport.com login. The system securely resolves the Supabase Auth user ID in the backend.
